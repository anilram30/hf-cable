# anilram30.github.io

The public site for the **[HF Cable Toolchain](https://github.com/anilram30/hf-cable-toolchain)** —
seven engineering packages that take a high-frequency automotive Ethernet cable from a raw
network-analyser measurement to a predicted link.

**Live at [anilram30.github.io](https://anilram30.github.io)**

## What is here

| path | contents |
|---|---|
| `index.html` | the system-level landing page — architecture, network, results |
| `projects/*.html` | seven engineering case studies, one per package |
| `system.html` | one sample followed through all seven packages, end to end |
| `assets/css/site.css` | design tokens and layout; light and dark are both explicitly designed, not auto-inverted |
| `assets/js/site.js` | theme toggle, map/list cross-highlighting, scroll spy — 120 lines, no dependencies |
| `assets/img/` | figures generated by the toolchain itself; every one is real output of real code |
| `assets/data/world-dots.svg` | the dot-matrix world map, generated from a land/ocean mask |
| `reports/` | the seven technical reports, 90 pages in total |

## Notes on how it is built

**No framework and no build step.** Nine static pages, one stylesheet, one script.
The landing page loads in well under a second and the site will still work in ten years.

**The map is generated, not drawn.** `assets/data/world-dots.svg` comes from a real land/ocean
mask sampled on a one-degree grid. Each row of land is emitted as a single dashed line with round
caps, so 7,683 dots cost 325 SVG elements and 16 kB instead of 7,683 circles and 174 kB. Site
symbols are displaced where two sites coincide at map scale — Roth and Kitzingen are 70 km apart —
which is standard cartographic practice, and the leader lines still resolve each symbol to its label.

**The numbers are real.** Every figure quoted on the site is produced by running the code in the
seven repositories. The interlaboratory comparison values come from `labplatform`'s analysis of a
simulated four-site network; the eye heights and validation errors come from `linktwin`'s test suite.

**The data is synthetic, and the site says so.** No proprietary or customer measurements appear
anywhere in the toolchain. That is deliberate: with a synthesiser as the ground truth, every claim
about accuracy can be checked against a known answer rather than asserted.
